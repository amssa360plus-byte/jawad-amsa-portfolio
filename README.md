# Jawad Amsa — Portfolio

Personal portfolio site for Jawad Amsa, a first-year Web Development student at YouCode, UM6P, focused on frontend development.

## Run locally

Open `index.html` in a browser. The projects section loads public, non-fork repositories from GitHub’s public API, so it needs an internet connection. The **Download CV** button downloads `Jawad-Amsa-CV.docx` from this repository.
